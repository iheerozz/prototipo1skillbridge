# SkillBridge – prototype

Working prototype of SkillBridge, a platform that connects university students with SMEs for short, paid projects (Startups & Strategy, cátedra de Milano).

- **Student app** (mobile): sign-up with university email, matched projects, map, apply, e-contract, workspace with milestones, wallet, certificates.
- **Company web app**: dashboard, post a project, find talent, hire with escrow, approve milestones, payments.

Both sides share the same data: what the company does on the web shows up on the student's phone.

Open `index.html` in a browser, or publish with GitHub Pages. Demo data only, except the founder's profile.
